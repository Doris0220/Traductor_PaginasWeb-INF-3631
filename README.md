# Traductor_PaginasWeb-INF-3631
El proyecto consiste en desarrollar un traductor para la generación de páginas web mediante un lenguaje propio,
utilizando Python, el sistema tendrá como finalidad recibir instrucciones escritas en un lenguaje diseñado específicamente
para el proyecto, analizarlas y generar como resultado los archivos necesarios para construir una página web.

El lenguaje propio estará orientado a la creación y estructuración de páginas web, permitiendo definir tanto los elementos
que conforman su contenido como las características que determinan su presentación visual. Además de elementos como títulos,
textos, imágenes, enlaces y botones, podrá contemplar. propiedades relacionadas con dimensiones, espaciado, tipografía,
colores, bordes, posicionamiento, distribución, transiciones y transformaciones.
Una de las características principales del proyecto será permitir que la estructura y el diseño de una página puedan
definirse mediante un mismo lenguaje, sin que el usuario tenga que escribir directamente HTML y CSS por separado.

Las instrucciones podrán encontrarse mezcladas dentro del código fuente, y el traductor será responsable de analizarlas,
identificar su función y organizar la información para generar los archivos correspondientes.
El sistema realizará diferentes procesos para traducir las instrucciones. Primero se llevará a cabo un análisis léxico para
reconocer palabras reservadas, identificadores, valores y símbolos. Posteriormente se realizará un análisis sintáctico para
comprobar que las instrucciones cumplan con las reglas establecidas. Finalmente, se realizará un análisis semántico para
verificar que las instrucciones sean válidas y que exista una relación correcta entre los elementos y sus propiedades.

Como resultado del proceso de traducción se generarán principalmente dos archivos: HTML y CSS. El archivo HTML representará
la estructura y contenido de la página, mientras que el archivo CSS contendrá las características relacionadas con su presentación visual.

El traductor también contará con un sistema de manejo de errores que permita detectar instrucciones desconocidas,
estructuras incorrectas, elementos no definidos, propiedades inválidas y otros errores relacionados con el uso del lenguaje.

### Objetivo 
Desarrollar un traductor en Python capaz de analizar y procesar un lenguaje propio para la generación de páginas web,
convirtiendo sus instrucciones en archivos HTML y CSS correctamente relacionados.
